# Dashboard de Desempenho Comercial — Excel

Dashboard interativo desenvolvido no Microsoft Excel para análise do desempenho comercial, permitindo acompanhar o lucro das vendas por produto, a evolução dos resultados ao longo do tempo e o ranking dos vendedores.

O projeto possui filtros por ano, análise mensal e semanal, ranking completo dos vendedores e destaque para os três melhores vendedores. Como diferencial visual, o dashboard também possui alternância entre **modo claro e modo escuro**.

## Objetivo do Projeto

Transformar uma base de dados de vendas em um dashboard visual e interativo, facilitando a análise do desempenho comercial dos vendedores e a identificação dos produtos e períodos com melhores resultados.

O dashboard permite analisar:

- Ranking dos vendedores;
- Desempenho individual dos colaboradores;
- Lucro por produto;
- Evolução mensal das vendas;
- Evolução semanal das vendas;
- Participação dos vendedores no resultado total;
- Top 3 vendedores;
- Comparação do desempenho entre vendedores;
- Resultados de acordo com o ano selecionado.

## Dados Utilizados

A base de dados contém informações relacionadas às vendas realizadas, permitindo analisar os resultados por período, produto e vendedor.

| Campo | Descrição |
| --- | --- |
| Data | Data em que a venda foi realizada |
| Vendedor | Vendedor responsável pela venda |
| Produto | Produto relacionado à venda |
| Valor | Valor obtido na venda |
| Ano | Ano em que a venda foi realizada |
| Período | Informações utilizadas para análises mensais e semanais |

## Funcionalidades do Dashboard

### Filtro por Ano

O dashboard possui um filtro para selecionar o ano que será analisado.

Ao alterar o ano, as informações apresentadas nos gráficos, indicadores, ranking e análises dos vendedores são atualizadas de acordo com o período selecionado.

### Ranking dos Vendedores

O painel de ranking apresenta todos os vendedores ordenados de acordo com o desempenho obtido.

São exibidos:

- Posição no ranking;
- Nome do vendedor;
- Resultado obtido.

Essa visualização permite identificar rapidamente os vendedores com maior e menor desempenho.

### Lucro por Produto

Os cartões dos produtos apresentam o resultado obtido por cada produto e um pequeno gráfico com sua evolução ao longo dos períodos.

Essa visualização permite comparar o desempenho dos diferentes produtos e observar como seus resultados variam ao longo do tempo.

### Análise Mensal

Gráfico que apresenta a evolução do resultado durante os meses do ano, permitindo identificar:

- Meses com maior desempenho;
- Meses com menor desempenho;
- Variações ao longo do ano;
- Tendências de crescimento ou redução.

### Análise Semanal

Gráfico utilizado para analisar o comportamento das vendas ao longo dos dias da semana.

A análise permite identificar quais dias apresentam maior ou menor volume de vendas e observar padrões no desempenho comercial.

### Análise dos Vendedores

Gráfico de barras que apresenta o desempenho individual de cada vendedor.

Os vendedores são organizados de acordo com seus resultados, facilitando a comparação entre os colaboradores.

### Top 3 Vendedores

O dashboard possui uma área dedicada aos três vendedores com melhor desempenho no período selecionado.

Para cada vendedor são apresentados:

- Foto;
- Nome;
- Resultado obtido;
- Participação percentual no resultado total.

As informações são atualizadas de acordo com o ano selecionado.

### Alternância entre Modo Claro e Modo Escuro

Um dos diferenciais do projeto é a possibilidade de alterar o tema visual do dashboard.

O usuário pode escolher entre:

- **Modo Claro:** interface com fundo claro e maior contraste entre os elementos;
- **Modo Escuro:** interface com fundo escuro e destaque para os principais indicadores.

A funcionalidade permite personalizar a visualização do dashboard de acordo com a preferência do usuário.

O projeto foi desenvolvido com foco não apenas na apresentação dos dados, mas também na experiência de utilização do dashboard.

- Destaque visual para o Top 3;
- Fotos dos vendedores;
- Análise mensal e semanal;
- Acompanhamento do desempenho por produto;

- Indicadores atualizados de acordo com os filtros;

## Objetivo de Aprendizado

Projeto desenvolvido para praticar Excel aplicado à análise de dados e à construção de dashboards, explorando recursos de visualização, tabelas dinâmicas, rankings, filtros, fórmulas e organização de informações comerciais.

O projeto também teve como objetivo desenvolver uma interface mais interativa e visualmente organizada, aproximando o dashboard de uma ferramenta utilizada para acompanhamento de indicadores comerciais.
